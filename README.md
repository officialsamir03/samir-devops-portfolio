# Shaikh Samir — DevOps & Cloud Portfolio

A responsive dark-theme portfolio made with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract `Samir_DevOps_Portfolio.zip`.
2. Open the `samir_devops_portfolio` folder.
3. Double-click `index.html` to open it in your browser.
4. For a smoother development workflow, open the folder in VS Code and use the Live Server extension (optional).

## Before publishing
- Review all personal details and ensure they are correct.
- Add your GitHub profile link and project repository/demo links when available.
- Add real screenshots of your project if you have them.
- Only change a learning area to a skill/experience claim when you have the practical knowledge to support it.
- The portfolio uses Google Fonts from the internet; system fonts will be used if unavailable.

## Files
- `index.html` — page content
- `style.css` — dark responsive design
- `script.js` — mobile navigation
